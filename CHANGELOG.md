# Changelog

All notable AquaTwin-X product milestones are recorded here.

## 0.1.0 - 2026-11-20

### Product

- Interactive water-network topology and EPANET INP import.
- Pipe-leak simulation with real WNTR/PDD and clearly labelled demo fallback.
- Manual valve isolation and Genetic Algorithm recovery optimization.
- Configurable GA runs with progress tracking and cancellation.
- Simulation history, filters, analytics and printable evidence reports.
- Batch experiments, benchmark comparison and downloadable evidence bundles.

### Delivery

- Docker Compose runtime for the React dashboard and FastAPI service.
- Linux CI validation using real WNTR hydraulic simulations.
- Reproducible full-benchmark workflow with retained evidence artifacts.
- Automated backend and frontend API workflow tests.
